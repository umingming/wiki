# Aseprite

## 개요

픽셀 아트와 도트 애니메이션 제작에 특화된 그래픽 에디터. 인디 게임 개발자들 사이에서 도트 그래픽 제작 도구의 사실상 표준으로 사용된다.

## 기본 정보

- **유형**: 픽셀 아트 에디터
- **라이선스**: 유료 (소스 코드 직접 빌드 시 무료)
- **무료 대안**: Libresprite (Aseprite 포크), Piskel (웹 기반)
- **공식 사이트**: aseprite.org

## 주요 기능

- 스프라이트 시트 내보내기
- 프레임 단위 애니메이션 (어니언 스킨 지원)
- 팔레트 관리, 색상 제한 작업
- 레이어, 태그 기반 애니메이션 관리
- 타일맵 모드
- CLI 배치 처리 (자동화 파이프라인 구성 가능)

## 관련 도구

| 도구 | 역할 |
|------|------|
| **Tiled** | 타일맵 에디터 — 건물 배치, 맵 구성 |
| **TexturePacker** | 스프라이트 시트 패킹 |
| **Lospec** | 팔레트, 튜토리얼 모음 사이트 |
